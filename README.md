# ZameenVerify

### AI-powered land record auditing for Pakistan

ZameenVerify analyzes Pakistani land records such as **Fard, Intiqal, Khasra, and Sale Deeds** to help identify potential fraud, title-chain breaks, and registry risks.

## What it does

- Upload multiple land-record documents in **PDF, JPG, or PNG** format.
- Extract information from typed/computerized and legacy documents.
- Analyze documents using AI to identify inconsistencies and potential risks.
- Generate a structured verification report.
- Verify generated reports through a dedicated verification page.

## Demo

You can try the application without using your own documents.

**[Download the sample documents](./demo)** and upload them to the [live application](https://zameenverify.vercel.app/).

> ⚠️ ZameenVerify is a due-diligence aid, not a legal authority. Important findings should always be confirmed against official land records.

## Tech Stack

**Backend:** Next.js API Routes · Supabase

**AI & Document Processing:** OpenAI · OCR · PDF processing · Sharp

**Other:** QR Code generation · Framer Motion · Vercel Analytics
